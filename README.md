# Site de divulgação da Códice

Página única, estática, que apresenta a plataforma Códice (displays inteligentes e
mídia de varejo) para varejistas, indústria e operadoras.

**No ar:** https://seashell-buffalo-304816.hostingersite.com

A Hostinger acompanha a branch `main` deste repositório pelo app do GitHub:
todo push publica sozinho em `public_html`, sem passo manual. Se o site ficar
para trás, o caminho é hPanel, Painel de controle do site, Avançado, GIT,
botão Reimplantar.

## Arquivos

```
index.html   a página inteira, com CSS e script embutidos
img/         renders dos displays (mesmos do sistema)
favicon.svg  símbolo da marca Códice
```

## Convenções

- Marca Códice: Midnight Navy `#061B49`, Electric Teal `#1DD4C8`, Intelligent Blue `#2F73FF`.
- Tipografia: Exo 2 nos títulos, Inter no texto.
- Sem travessão no texto da página.
- Nenhum número de cliente inventado: os dados do mockup são ilustrativos e a
  seção de honestidade repete os limites que o produto assume.
